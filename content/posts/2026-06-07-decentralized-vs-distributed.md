"Decentralized" and "distributed" get used interchangeably, but they're not the same thing.

This is a quick set of notes to capture what I've been thinking about. I hope to expand on each of these in a future post.

## Incentives by Systems

Distributed systems coordinate. Decentralized systems incentivize.

The difference shows up in how each one keeps its participants aligned.

## Step Subset

A distributed system is often just a subset of steps in a larger process — the same job, split across many workers.

## Bees vs Humans

A beehive is distributed but not decentralized — every bee runs the same program toward a shared goal.

Humans are decentralized — each one optimizing for their own incentives, loosely coordinated.

## Code vs Process

Code is distributed. Process is decentralized.

One is deterministic and replicated. The other is negotiated between independent actors.

## Ender's Game

Ender commands a distributed fleet that behaves as one mind, against a decentralized enemy.

## Management

Managing a distributed team vs. managing a decentralized one — different problems entirely.
